 Cricket Career PWA

## What this is
An installable Progressive Web App version of Cricket Career.

## Features
- Offline gameplay after the first successful load
- Installable from a supported browser
- Standalone app window
- Toss, batting/bowling decision and match situations
- T20 / ODI / Test
- Career rating, form, seasons, awards and selection
- Match history and statistics
- Career saved with localStorage

## Important
A service worker normally requires HTTPS or localhost. Opening index.html directly as a file may show the game, but the browser may not allow PWA installation/offline service-worker features.

For the easiest phone-only deployment, upload this folder to a static HTTPS host such as GitHub Pages, Netlify, or Cloudflare Pages, then open the HTTPS address in Chrome and choose:
Chrome menu -> Add to Home screen / Install app.
